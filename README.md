# SpringBoot Project Stock&News  
스프링부트 기반 웹 프로젝트 스톡앤뉴스  

## 프로젝트 소개  
비동기 웹 크롤링을 활용하여 네이버 KOSPI·KOSDAQ 종목 데이터와 국내·외 금융 뉴스를 수집·가공하고, 이를 실시간으로 제공하는 웹 서비스
